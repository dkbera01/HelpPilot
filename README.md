# HelpPilot

> A production-oriented AI customer support platform built to learn, design, and implement modern Agentic AI systems using the OpenAI Agents SDK.

## Overview

HelpPilot is the first project in my AI Engineering journey.

The goal is not just to build another AI chatbot, but to build a production-quality AI application using modern software engineering practices.

This project focuses on designing AI systems that are maintainable, observable, scalable, and ready for real-world deployment.

---

## Goals

- Build production-ready AI applications
- Learn Agentic AI through real projects
- Apply modern software engineering principles
- Explore AI system architecture
- Create a portfolio suitable for AI consulting opportunities
